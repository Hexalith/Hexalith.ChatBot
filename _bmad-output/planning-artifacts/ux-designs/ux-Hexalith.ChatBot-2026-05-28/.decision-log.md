# UX Decision Log

Project: Hexalith.ChatBot
Created: 2026-05-28
Status: discovery

## 2026-05-28 Intake

- Interface: chatbot-inspired experience, referencing operating principles from Claude Code, Claude Cowork, OpenAI Codex, and ChatGPT.
- Primary interaction: user interacts with AI and other actors in the context of a folder or project.
- UI foundation: must use Hexalith.FrontComposer, integrated as a submodule of the main project.
- UI system: FrontComposer uses Microsoft Blazor Fluent UI version 5.
- Differentiator: not a classic one-to-one chatbot; must support multi-actor conversation tracking via Hexalith.Conversations.
- Actors: conversations may involve LLM agents, internal users, or external actors modeled in Hexalith.Parties.
- Context anchor: every conversation belongs to a folder or project represented by Hexalith.Projects.
- Document model: associated documents are preserved, organized, and indexed through Hexalith.Folders and Hexalith.Memories.
- Product goal: centralize, follow, and understand all conversations we participate in by placing them in project, document, and relationship context.
