## Bootstrapped Decisions

### 2026-05-10 - Product Direction

- Hexalith.ChatBot is defined as a B2B SaaS product for enterprise collaboration and AI project workspace workflows.
- The MVP focuses on governed email-to-project collaboration rather than a general email client, helpdesk, CRM, workflow builder, or unrestricted AI automation product.
- Email is the first channel because external customer, supplier, and partner collaboration already happens there.
- The product acts as an orchestration layer and does not own core project records, files, parties, tenants, identity, or event history.

### 2026-05-10 - MVP Scope

- The MVP must prove one complete loop: inbound project email, project association, governed attachment handling, task-intent capture, AI action mediation, approval where needed, command execution, and auditable projection back into the workspace.
- Microsoft 365 / Exchange-style controlled mailbox integration is the primary mailbox integration target for MVP.
- CLI and MCP parity are included in MVP scope so automation builders and AI agents use the same governed command model as human users.
- Generic email support and non-Microsoft mailbox sources are allowed only if they satisfy the same controlled mailbox contract.

### 2026-05-10 - Governance And Safety

- Project association must prioritize deterministic evidence over AI inference.
- Ambiguous association must fail closed into visible user review with candidate evidence.
- Unauthorized projects, evidence, files, audit details, CLI output, and MCP payloads must not be exposed.
- Authorization is enforced at command and query boundaries across UI, CLI, and MCP.
- Risky AI actions require approval before modifying project state, exposing file content, sending outbound communication, invoking external tools, creating or assigning tasks, or acting on behalf of a participant.

### 2026-05-10 - Architecture Boundary

- Hexalith.ChatBot owns AI-mediated collaboration workflows and user-facing assistant interactions.
- Hexalith.Projects owns project identity, membership, and project conversation boundaries.
- Hexalith.Parties owns internal and external participant identity resolution.
- Hexalith.Folders owns governed project folders, attachment storage, file access control, and file metadata.
- Hexalith.Tenants owns tenant facts, boundaries, policies, and authorization context.
- Hexalith.EventStore supports command/event flow, projections, retries, duplicate suppression records, and audit-friendly outcomes.
- Mail integration owns message capture, headers, attachments, delivery state, and Microsoft 365 / Exchange synchronization concerns.
