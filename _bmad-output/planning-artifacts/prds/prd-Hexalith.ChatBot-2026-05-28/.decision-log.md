## 2026-08-01 — A10 remains provisional after Story 12.15 local validation

Architecture/DevOps retained the existing A10/NFR56 values as provisional targets: RPO ≤ 15 minutes and RTO ≤ 4 hours. The values were not tightened or loosened, so `RecoveryTargets.MaxRpo` and `RecoveryTargets.MaxRto` remain unchanged.

Story 12.15 stood up live Aspire/DAPR fault injection and ran it locally, but **no measured figure is published from it**. The local diagnostic bundle passed the evidence gate as that gate existed mid-story; it predates the current evidence-manifest contract (it carries no `MeasurableRecoveryCeilingSeconds`, which the shipped gate requires) and therefore cannot be replayed or independently checked. Its run identifier and values were withdrawn from this entry, the addendum and the predecessor ADRs rather than restated with caveats. No external CI pass is claimed.

Two limits bound what a future hosted pass can ratify. The lane's restoration budget is **180 seconds** against the 4-hour RTO, so a pass ratifies recovery within that ceiling and never demonstrates a miss of the target; the gate emits a non-blocking `target_exceeds_measurable_ceiling` claim limitation on every such run. And the measured RPO is currently a constant on the no-loss path, so the 15-minute target is only ever evaluated on a run that has already breached.

Residuals `RV-EXT-M365`, `RV-DURABLE-WORM`, `RV-PROD-CONTROL`, `RV-PROVIDER-SCALE`, and `RV-MEASURABLE-CEILING` remain open. Hosted lanes have run but have not produced a complete passing recovery bundle: required release run [32705581758](https://github.com/Hexalith/Hexalith.ChatBot/actions/runs/32705581758) failed the live producer and independent gate and retained topology evidence only; scheduled runs on 2026-08-09, 2026-08-16, and 2026-08-23 failed before recovery production. The scheduled CI and release workflows retain their evidence artifacts for 30 days. Note the asymmetry between that retention and the gate's `MaximumEvidenceAge` of **8 days** — an artifact aged 8–30 days is still downloadable but is no longer citable for ratification. A successful hosted lane and recorded run/artifact locator are necessary but not sufficient for A10 ratification: the 4-hour RTO also needs a full-window lane or separately evidenced pre-production drill, and the 15-minute RPO needs a citable non-constant loss-path measurement. A10 remains provisional until those bounds are genuinely evidenced.

**Un-ratification:** a ratified A10 returns to provisional when the cited artifact ages past the 8-day `MaximumEvidenceAge` freshness boundary without a successor, when a later required run is not passing, or when a hosted run returns `Unmeasurable` or a structural breach. The artifact remains retained through day 30 for investigation only. Architecture/DevOps owns that transition and records it here.
