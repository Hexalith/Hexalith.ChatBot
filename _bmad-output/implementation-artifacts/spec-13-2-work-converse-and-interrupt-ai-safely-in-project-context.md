## Intent

**Problem:** The conversation route cannot safely deliver Story 13.2: healthy reads render degraded, secured UI calls lack the contributor token, cancellation targets the wrong aggregate and treats a request as terminal, synchronous AI execution is not stoppable, history/project switches lose authoritative state, and browser tests skip the real workflow.

**Approach:** Complete one conversation-centric, event-sourced lifecycle from authenticated UI admission through asynchronous AI execution, cancellation confirmation, typed projection refresh, accessible rendering, and real-route acceptance evidence.

## Boundaries & Constraints

**Always:** Authorize tenant/project before access; derive risk/authority server-side; persist lifecycle only through EventStore; treat SignalR as a metadata-only requery nudge; preserve Fluent V5, EN/FR, focus/live regions, redaction, exact concurrency, and warnings-as-errors.

**Ask First:** Any breaking public contract, identity-provider claim/client redesign beyond the existing `hexalith-chatbot` OIDC client, or change required inside a sibling submodule.

**Never:** Edit the dirty EventStore/Tenants submodules; add direct persistence; trust client risk/tenant/actor claims; project a cancellation request as completed; ship fabricated project choices; clear drafts before admission; or claim acceptance from source scans, `SetContentAsync`, screenshots, or a diagnostic fallback alone.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Workspace | no project, empty, active, switch, history | Correct state; newest truth stays visible; older items merge without forced scroll | Opaque denial; degradation keeps the last safe same-project view |
| Submit | Message/Ask-AI, including version `0` | Authenticated admission; risky AI becomes proposal; draft clears after acceptance | Blank focuses validation; rejection preserves draft and safe action |
| Stop | active exact identity/version | Aggregate records Cancelling; executor confirmation becomes stopped | Wrong/stale/terminal/duplicate targets fail closed/no-op without fake success |
| Race/recovery | completion race, duplicate nudge, reconnect, late load | Typed requery wins; natural completion is not announced stopped; focus returns once | Stale responses cannot overwrite newer state; reconnect rebuilds/rejoins |
| Presentation | EN/FR; supported widths/modes | Attribution, redaction, status, action, focus, announcements remain usable | No color/motion-only meaning or clipped critical action |

## Design Notes

Use the started progress conversation id as the shared aggregate identity while retaining an explicit compatibility path for already-persisted state-owning streams, Started events, work indexes, and cursors. Record the authoritative EventStore stream version of the Started event on the active generation and on in-flight progress; Stop's `ExpectedSourceVersion` is that Started sequence, not proposal+1 and not a later cancelling/progress sequence. A persisted Started event/outbox signal—not a gateway submit receipt—owns provider scheduling. Executor terminal commands require a protected internal admission marker that an authenticated contributor cannot manufacture, and the same types must be findable in `ChatBotCommandAdmissionCatalog` so `RevalidateMarkedCommitAsync` does not return `command-not-allowlisted`.

Production must fail startup unless the DAPR-backed work store is enabled; process-local storage is Testing/Development-only. The coordinator uses canonical collision-free identity encoding, stable ULID terminal ids, unioned legacy/current indexes that collapse duplicates even when the preferred row is leased, bounded rotating reads, constant-bounded insertion, compaction that removes terminal and quarantined keys from runnable pages, and quarantine that suppresses poisoned sources. Leases fence commits. A provider invocation that ignores cancel or exceeds its slot deadline keeps occupying that slot until the task ends; the host drains claimed work before the hosted service returns. A terminal relay remains pending until persisted truth is observed. Terminal-attempt counters increase only when a terminal submit fails. Exhausted work is discoverable and recoverable through authenticated operator operations. Cancellation requested against a generation whose work row does not yet exist must remain durable (replayable intent without inventing Execution). Cancellation moves Active to Cancelling; cancellation failure restores the same active/runnable identity in aggregate, work, and projection (non-terminal progress, Stop still enabled); observed cancellation alone confirms stopped; persisted natural completion beats a racing Stop; and provider approval remains proposal-gated.

Every UI effect carries its request id and project id, plus accepted command/item and generation identity when applicable; a project switch invalidates all old-scope identities, and effects recheck scope before every delayed poll or dispatch. Submit verification waits for the admitted item itself. Cancellation verification starts when Stop is accepted and lasts the server recovery/lease duration from that instant (additive `RecoveryDeadlineUtc` is Stop-relative, never Started.OccurredAt plus two minutes used as a wall-clock instant that can already be past). Authoritative coverage is the contiguous owner-stream source-version interval of items on the page—messages, approvals, attachments, and AI progress—and omissions inside that interval are purged, including an all-covering empty result, while rollover outside it is retained. Every non-terminal generation exposes Stop. History failures do not disable the composer. SignalR stores only authoritative reload watermarks, obtains current circuit-scoped tokens, recreates closed/exhausted connections, and serializes dispose with subscribe. Production fails startup for absent, partial, malformed, or non-HTTP(S) OIDC configuration. Treat the stateful fake route as supporting proof only; production acceptance keeps the real client, authentication, CommandGateway, EventStore, and SignalR path. Do not edit Hexalith.CiCd-owned workflow YAML; put a `[Fact]` with the already-wired method name on the IntegrationTests type those jobs execute, resolve Chrome via Playwright, and assert admitted Message/Ask-AI/confirmed Stop plus every presentation invariant on each of the 24 rows.

Conversation projection item documents may replace on last-write; conversation and intake indexes must merge item-id sets from the CAS winner. `ExecuteAsync` must not abandon in-flight `ProcessClaimedAsync` tasks. Pooled cancel of a provider CTS must tolerate disposal.
